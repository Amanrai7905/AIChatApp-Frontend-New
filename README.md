# AI Chat App - Frontend

## Overview

React frontend for the AI Chat application.

## Features

- User Registration
- User Login
- JWT Authentication
- AI Chat Interface
- Responsive UI
- Docker Support

## Technologies

- React
- Vite
- Axios
- Nginx
- Docker

## Run

```bash
docker compose up --build
```

Frontend:

http://localhost:3000
